Campus Transit Database Schema

A relational database to track bus arrivals and help reduce campus overcrowding.

MISSQLERD
+

Goal

Store bus arrivals and rider counts so planners can spot overcrowded routes and times.

Schema

CREATE TABLE routes (
  route_id   INT PRIMARY KEY,
  route_name VARCHAR(50) NOT NULL
);
CREATE TABLE stops (
  stop_id   INT PRIMARY KEY,
  stop_name VARCHAR(80) NOT NULL,
  campus    VARCHAR(30)
);
CREATE TABLE buses (
  bus_id   INT PRIMARY KEY,
  route_id INT REFERENCES routes(route_id),
  capacity INT NOT NULL
);
CREATE TABLE arrivals (
  arrival_id INT PRIMARY KEY,
  bus_id     INT REFERENCES buses(bus_id),
  stop_id    INT REFERENCES stops(stop_id),
  arrived_at TIMESTAMP NOT NULL,
  riders     INT
);

Sample query: most crowded stops

SELECT s.stop_name,
       ROUND(AVG(a.riders * 1.0 / b.capacity), 2) AS avg_load
FROM arrivals a
JOIN buses b ON a.bus_id = b.bus_id
JOIN stops s ON a.stop_id = s.stop_id
GROUP BY s.stop_name
ORDER BY avg_load DESC
LIMIT 5;
